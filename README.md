# Automatic-Touchless-Door-Control
Touchless door system using Arduino and IR sensor
## 📌 Overview
This project is a touchless door system using an IR sensor, Arduino UNO, and servo motor. It opens and closes automatically without physical contact.

## 🎯 Features- 
Touchless operation- Two-detection trigger (avoids false signals)- Auto close after 5 seconds- LED indicator## 
⚙️ Components Used-
Arduino UNO- IR Sensor- Servo Motor (SG90)- LED## 
🔄 Working
1. IR sensor detects hand
2.   Arduino counts detections
  3. After 2 detections → Door opens
  4. LED turns ON
  5. After 5 seconds → Door closes
